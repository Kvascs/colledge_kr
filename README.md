# Movies API

Учебный проект: REST API для каталога фильмов на FastAPI.

## 🎯 Описание проекта

Асинхронное приложение, которое хранит каталог фильмов в базе данных SQLite и позволяет работать с ним по HTTP: создавать, просматривать, изменять и удалять фильмы, а также фильтровать и сортировать список. Код разделён на слои: модели БД, схемы валидации, репозиторий (работа с базой) и роутеры (эндпоинты).

## 🚀 Основные возможности

- **CRUD-операции** над фильмами (создание, чтение, полное и частичное обновление, удаление)
- **Фильтрация и сортировка** списка фильмов по году, рейтингу и названию
- **Пагинация** списка (`limit` и `offset`)
- **Валидация данных** на уровне API (Pydantic) и на уровне базы данных (CHECK-ограничения)
- **Асинхронная работа с БД** через SQLAlchemy 2.0 и aiosqlite
- **Миграции** базы данных с помощью Alembic
- **Автоматическая документация** API: Swagger UI по адресу `/docs`

## 🛠 Технологический стек

- **Python 3.10+**
- **FastAPI** — веб-фреймворк для создания API
- **Uvicorn** — ASGI-сервер для запуска приложения
- **Pydantic** — валидация и сериализация данных
- **SQLAlchemy 2.0** — ORM (асинхронный режим)
- **SQLite + aiosqlite** — база данных и асинхронный драйвер для неё
- **Alembic** — миграции базы данных

## ⚡ Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-логин>/movies_api.git
cd movies_api
```

### 2. Установка зависимостей
Рекомендуется виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

pip install -r requirements.txt
```

### 3. Применение миграций
Команда создаёт файл `movie.db` и таблицу `movies`:
```bash
alembic upgrade head
```

### 4. Запуск приложения
```bash
uvicorn src.main:app --reload
```

После запуска API доступно по адресу `http://127.0.0.1:8000`, интерактивная документация — `http://127.0.0.1:8000/docs`.

## 🎬 Основные эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/` | Проверка состояния API |
| `GET` | `/movies/` | Получить список фильмов (с фильтрацией и сортировкой) |
| `GET` | `/movies/{id}` | Получить фильм по ID |
| `POST` | `/movies/` | Создать новый фильм |
| `PUT` | `/movies/{id}` | Полностью обновить фильм |
| `PATCH` | `/movies/{id}` | Частично обновить фильм |
| `DELETE` | `/movies/{id}` | Удалить фильм |

Если фильм с указанным ID не найден, API возвращает `404`. При некорректных данных — `422`.

Пример создания фильма:
```json
POST /movies/
{
  "title": "Inception",
  "genre": "sci-fi",
  "rating": 8.8,
  "year": 2010
}
```

## 🔍 Фильтрация и сортировка

Параметры запроса `GET /movies/`:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `year_min` | минимальный год выпуска | — |
| `year_max` | максимальный год выпуска | — |
| `min_rating` | минимальный рейтинг | — |
| `order_by` | сортировка: `title`, `-title`, `year`, `-year`, `rating`, `-rating`, `id`, `-id` (знак `-` — по убыванию) | `-rating` |
| `limit` | количество записей (от 1 до 100) | 50 |
| `offset` | смещение для пагинации | 0 |

Пример запроса:
```
GET /movies/?year_min=2000&min_rating=7.0&order_by=-rating&limit=10
```

## 🗄️ Модель данных

### Фильм (Movie)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | int | уникальный идентификатор (создаётся автоматически) |
| `title` | str | название фильма, 2–200 символов |
| `genre` | str | жанр, 2–100 символов |
| `rating` | float | рейтинг от 0.0 до 10.0 |
| `year` | int | год выпуска, от 1888 до текущего года |

### Ограничения базы данных

В таблице `movies` заданы CHECK-ограничения (добавляются миграциями Alembic):

- `check_movie_rating_range` — рейтинг должен быть от 0 до 10;
- `check_movie_year_1888` — год выпуска не может быть меньше 1888 (год появления кинематографа);
- поля `title`, `genre`, `rating`, `year` не могут быть пустыми (`NOT NULL`).
